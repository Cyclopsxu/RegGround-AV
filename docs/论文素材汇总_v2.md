## 六、影子评估线(RAG+LLM 作用的直接量化)

45. **设计**:disable_rule_engine × 118 决定性候选,冻结输入/benchmark 不动;对照标签纯几何谓词,对 LLM 非循环;标注"118 条偏 easy,上界参考,不外推 382 主池"。
46. **v_a 主结果四元组**:一致率 68.6% / 弃权 30.5% / **false_veto 0%** / 排除弃权后 **98.8%**(81/82)。错误方向完全不对称:弱点全部表现为弃权,几乎不错判——对偏好打标最良性的失效模向。
47. **分层**:行人轴 88.9% 一致 / 8.3% 弃权,`zone_time_overlap` 类 94.7% 零弃权——**行为接地价值最硬的量化**;红灯越线类 23.7% / 弃权 76.3%。
48. **v_a/v_b 措辞对照**:v_b(补"t∈[0,2s] 相位持续有效")一致率 89.0% / 弃权 8.5% / false_veto 4.9% / 排除弃权后 97.2%。红灯越线类 29 弃权→1。**+20.3pp = 一句话的信息传达价值**;预注册 ≥90% **未达**(如实保留);单次对照、含少量判定方差(caveat)。
49. **作用域泄漏(机理复核后口径)**:存在性结论 + 中等强度机理("无作用域声明重设证据充分性标准、提高停止线概念显著性并外溢至行人规则");支持样本 `0225...` 四条 + `bc73...`(后者:v_b 忽略"距线 5.6m/总行程 2.1m"的充分间接证据——泄漏既致过度自信也**挤占推理路径**);`7dad.../traj_d` 剔除为独立波动。设计原则用条件式:"认识论声明应显式限定管辖对象"。**不出 v_c,评估臂 closed。**
50. **`575b.../traj_a` 解释性分歧样本**:两版稳定 cleared vs 谓词 vetoed,全数据唯一"两裁判坚定互不相让";已入盲标补充批,人类仲裁后成"三裁判仲裁机制"案例(谁对都是素材)。
51. **生产停留 v_a 的三条理由**:零错杀性质 / 极端案例已由谓词分工承接 / 全局措辞的作用域泄漏风险。
52. **弃权-信息承诺曲线(讨论章主线)**:v1 无 digest 弃权 68.5% → v_a 快照声明 30.5%(集中于快照覆盖外)→ v_b 有效窗声明 8.5%(残余为真欠定)——**弃权率沿输入承诺的信息范围单调收缩,末段付出作用域泄漏代价**。与全量红灯 42.7% 互证:同一现象两次观测。
53. **"约定接地"概念**:三重接地(法规/事实/行为)之外的第四维——事实的有效范围与裁判间隐含约定需显式传达(谓词知道 2s 窗而 LLM 不知道 → 两裁判对同一事实各自正确却不同判)。不改 thesis,讨论章点出。
54. **答辩弹药("规则引擎都能判,LLM 干嘛")**:382/510 裁定量 + 全部偏好排序(328 pairwise)由 LLM 完成 + 独立复判 98.8% 一致零错杀 → 谓词裁极端 = 用免费确定性换昂贵调用,非不信任。
55. **答辩弹药("弃权多是不是不行")**:76% 集中单一语义(33/33)→ 补一句声明降到 8.5% → 不是模型不行,是输入少说一句话,而系统把这句话的缺失精确暴露 = 弃权机制正常工作。
56. **循环性答辩口径**:共享谓词架构的固有性质,破解靠外部背书(predicate_human_agreement + kappa)而非改代码;summary 自标 not_reported 是诚实性证据。
